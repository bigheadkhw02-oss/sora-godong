# 마법의 소라고동 웹앱 v4

변경 사항
- 질문 입력창 제거
- 줄 당기기 제거
- 소라고동 터치만으로 랜덤 답변 출력
- 보라색 소라고동 그래픽을 SVG로 교체
- 설치 가능한 PWA 구성 강화 (manifest + 아이콘 + 서비스워커)
- 설치 버튼 추가

## GitHub Pages 적용 방법
1. 기존 저장소 파일을 모두 이 폴더 내용으로 덮어쓰기
2. 특히 아래 파일/폴더를 같이 업로드
   - index.html
   - style.css
   - script.js
   - manifest.json
   - sw.js
   - assets/conch-shell.svg
   - icons/icon-192.png
   - icons/icon-512.png
3. GitHub Pages가 켜져 있으면 몇 분 뒤 자동 반영됨
4. 예전 화면이 보이면 브라우저에서 새로고침 또는 사이트 데이터 삭제 후 다시 접속

## 설치 방법
- 설치 버튼(⬇)이 보이면 눌러 설치
- 설치 버튼이 안 보이면 브라우저 메뉴에서 **홈 화면에 추가** 선택

## 참고
이 버전의 소라고동 이미지는 앱용으로 직접 만든 SVG 그래픽입니다.

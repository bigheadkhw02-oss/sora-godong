# 마법의 소라고동 v3

GitHub Pages에 그대로 업로드해서 사용하는 모바일 웹앱(PWA)입니다.

## v3 변경점
- 최근 대답 제거
- 질문 제목 문구 제거
- 소라고동 껍데기는 고정, 줄 손잡이만 당겨지는 방식
- 줄을 충분히 당기면 임계점 표시 및 탄성 복귀
- 답변 등장 애니메이션과 카드 광택 효과
- 효과음(Web Audio), 진동, TTS
- 설정값 자동 저장
- 답변 대폭 확장 및 직전 답변 연속 중복 방지
- 질문 지우기 버튼, 빠른 질문 3개
- 모바일 세로 화면 최적화
- 오프라인 캐시 버전 갱신

## GitHub Pages 배포
기존 저장소의 아래 파일을 전부 덮어쓰세요.
- index.html
- style.css
- script.js
- sw.js
- manifest.json

Pages가 이미 켜져 있다면 업로드 후 보통 잠시 뒤 자동 반영됩니다.
기존 화면이 남으면 브라우저 새로고침 또는 사이트 데이터/캐시를 한 번 갱신하세요.

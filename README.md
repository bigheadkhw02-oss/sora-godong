# 마법의 소라고동 웹앱

휴대폰만으로 GitHub Pages에 올려 사용할 수 있는 PWA 웹앱입니다.

## 업로드 방법
1. GitHub에서 새 저장소를 만듭니다. 예: `magic-conch`
2. 이 폴더의 파일 6개를 저장소 최상위에 업로드합니다.
3. 저장소 `Settings` → `Pages` → `Deploy from a branch`
4. Branch를 `main`, Folder를 `/ (root)`로 선택 후 저장합니다.
5. 생성된 `https://아이디.github.io/magic-conch/` 주소로 접속합니다.
6. Chrome/삼성 인터넷에서 `홈 화면에 추가`를 선택하면 앱처럼 사용할 수 있습니다.

## 포함 기능
- 질문 입력
- 소라고동 탭/아래로 당기기
- 100개+ 랜덤 답변
- 혼돈 모드 추가 답변
- 진동
- 한국어 TTS
- 최근 답변 기록
- 공유
- PWA 오프라인 캐시

## 참고
현재 소라고동 이미지는 저작권 문제를 피하기 위해 CSS로 만든 자체 일러스트입니다. 개인적으로 원본 이미지를 쓰려면 직접 파일을 추가해 CSS 배경을 교체하면 됩니다.
